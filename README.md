
# Student Task Manager

## About
A simple web application to manage college tasks.

## Features
- Add tasks
- Mark tasks as completed
- Delete tasks
- View total, pending and completed tasks
- Responsive design

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
Open index.html in a web browser.

## Future Improvements
- Save tasks permanently
- Add due dates
- Add student login
